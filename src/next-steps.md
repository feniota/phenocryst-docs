# Next Steps

## If You Are a Player

You should now have the Phanerite launcher downloaded. Just open it, enter the ~~magic~~ code given
by your server owner, log in with the account you registered on the link your server owner provided,
optionally set your skin, and wait a bit for the game to start.

## If You Are a Server Owner

Aphanite needs configuration before it can do its job. Head over to
[Aphanite's documentation](/aphanite/) for details.

## Found a Bug / Have a Suggestion / Want to See the Source / Want to Contribute?

Both Aphanite and Phanerite are open source software. Their repositories:

- Aphanite: [Forgejo](https://git.feniota.org/feniota/aphanite) ·
  [GitHub](https://github.com/feniota/aphanite)
- Phanerite: [Forgejo](https://git.feniota.org/feniota/phanerite) ·
  [GitHub](https://github.com/feniota/phanerite)

(The projects are primarily maintained on a private Forgejo instance. GitHub is a mirror with
identical contents, where the community can contribute issues and PRs.)

If you find a bug or have a suggestion, you're welcome to open an issue on GitHub!

### Pull Requests

Pull requests are very welcome!

When contributing, please set the merge target of your PR to the `github` branch. (Once your PR is
merged, the changes are automatically synced to Forgejo. After they are merged into `main` on
Forgejo, they are automatically pushed back to GitHub.)

(Please note that for code entirely generated by AI, we may take a stricter stance during review.)
